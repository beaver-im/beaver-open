## 使用规则

- 从 [TEMPLATE.md](TEMPLATE.md) 复制为下一个顺序编号 + 描述文件名，再加入索引。
- 新提案先标“提议”，不能把 AI 的建议直接标“已接受”；写明决策者/确认依据，未知则标待确认。
- 记录背景、选择、影响、替代方案、证据、验证和后续复审条件；历史动机缺失就写未知。
- 已接受决策被替换时保留旧页并标“被 ADR xxxx 替代”，不得悄悄改写历史。
- 只有目录边界、命名体系、鉴权模型等长期选择需要 ADR；普通实现细节进模块指南，任务进度进 tasks。
- 决策变化同时核对根入口、规范页和校验脚本，避免三份相互矛盾。
